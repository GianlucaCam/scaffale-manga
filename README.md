# Scaffale Manga

Lettore manga personale per iPad. Carica gli zip delle scan (volumi interi con una cartella per capitolo, o capitoli singoli), li organizza per serie e volume e ricorda dove sei arrivato.

Funziona offline: aprilo una volta da Safari, poi Condividi → "Aggiungi alla schermata Home". Le pagine restano salvate sul dispositivo, non su GitHub.
